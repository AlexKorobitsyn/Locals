# Карта местной сцены

На сайте появилась страница `/map` и пункт «Карта» в навигации.
В разделах событий и площадок есть переходы «Карта событий» и «Карта площадок».
`/map?layer=venues` открывает карту площадок без слоя событий.

Площадки отображаются сразу, даже если у них нет афиши. Зелёные метки и счётчик
выделяют места с событиями за выбранный период; фиолетовые обозначают остальные
площадки. События без площадки показываются отдельными оранжевыми метками.
Нажатие открывает название и карточку места с афишей и переходом к добавлению события.

Карта загружает опубликованные записи в видимой области. Город, период и тип
события фильтруют афишу; по умолчанию показываются предстоящие события.
Запросы после перемещения карты выполняются с небольшой задержкой. Одна страница
содержит до 100 объектов; при большем количестве есть кнопки дополнительной
загрузки и отображается число загруженных записей относительно общего количества.

## Добавление

- `/venues/new`: выбрать город, поставить точку на карте, заполнить название и адрес.
  Широта и долгота заполняются автоматически; их можно уточнить вручную.
- `/events/new`: выбрать площадку нажатием на её метку либо в списке. Город и
  координаты события берутся из площадки. Без площадки можно выбрать город и
  поставить отдельную точку. Остальные поля — название, время и тип события.
- `/events/new?venue_id=ID` заранее выбирает площадку. Такой переход есть
  в карточке площадки и на общей карте.

На подробных страницах события и площадки тоже отображается карта.
«Афиша площадки» выдаёт только её события через фильтр `venue_id`.

Связь с площадкой уже существовала в БД. API теперь возвращает её координаты
также в коротких карточках. Для связанных событий ответы и географические фильтры
используют актуальный город и координаты площадки, включая её последующий перенос.
События без площадки используют собственные координаты.
Добавлен публичный `GET /api/v1/cities/{city_id}` для центрирования карты по городу.
Миграция для этих изменений не требуется.

Обычные участники отправляют площадки и события в очередь предложений; до принятия
они не отображаются на публичной карте. Подтверждённые организаторы и сотрудники
публикуют напрямую. Эти правила сохраняют существующую систему опыта.

## Подложка и конфигурация

Используется [Leaflet 1.9.4](https://leafletjs.com/reference.html) с картографической
подложкой OpenStreetMap и видимой атрибуцией. Для Compose настройка `MAP_TILE_URL`
читается из корневого `.env`, для Vite dev/preview — из `frontend/.env`.
Она передаётся через `/config.json`, поэтому образ не требуется пересобирать
для изменения URL подложки.

```dotenv
MAP_TILE_URL=https://tile.openstreetmap.org/{z}/{x}/{y}.png
```

Картографическая подложка загружается из внешнего сервиса. Если она недоступна,
сайт сообщает об этом; метки и выбор координат продолжают работать.
Карты загружаются отдельным JavaScript-модулем при открытии соответствующего
экрана. Каталог музыки не загружает Leaflet заранее.

Массовый импорт площадок оставлен для следующего этапа.
