# Алерты Locals

Правила Alert и конфигурация Alertmanager в [vmalert-values.yaml](k8s/logging/vmalert-values.yaml).

 LocalsLoginErrors - Ошибки входа >5% за 5 минут, минимум 10 операций. 1 метрики сервиса
 LocalsAudioUploadErrors - Ошибки загрузки аудио >5% за 5 минут, минимум 10 операций. 2 метрики сервиса
 LocalsHttpRequestErrors - HTTP 5xx >5% запросов API за 5 минут, минимм 20 запросов.(FASTAPI метрики рантайма, фреймворка) 1
 LocalsProberScenarioUnavailable - Сценарий неуспешен, результат меньше 90 секунд, пробер работает. По сути прогнать сценарий пробера.
[AllErrors](k8s/logging/screenshots/Alerting/AlertsNotActive.png)
Для бизнесовых доля ошибок - `error / (success + error)`, rejected исключил. Для HTTP `5xx / все статусы`, health-check и /metrics исключены.
ПОЧЕМУ ВЫБРАЛ ТАКИЕ?: Вход и загрузка - основные пользовательские действия, HTTP 5xx показывает серверные сбои, а пробер проверяет доступность сценариев. Охватывают самое необходимое в работе сервиса.
