# Locals в Kubernetes

Locals разворачивается в однонодовом minikube с Docker runtime. Образы backend, frontend и MinIO собираются существующими Dockerfile через minikube.

## Абстракции Kubernetes

- **Namespace `locals`** - отделяет ресурсы приложения.
- **ConfigMap** - хранит адреса сервисов, порты, лимиты и т.д.
- **Secret** - пароли, JWT-секрет и URL подулючения к БД.
- **Deployment** - управляют репликами FastAPI и Nginx. масштабирую на видео бэк до 3, фронт до 2.
- **StatefulSet** - запускают PostgreSQL и MinIO.
-  **PVC** - сохраняют БД и медиа при пересоздании подов. Тома выделяет StorageClass minikube.
- **Service** дают постоянные имена app, frontend, db и storage. Service backend распределяет новые соединения между готовыми репликами. 
- **Job** отдельно выполняют миграции Alembic и инициализацию bucket.
- **Startup/readiness/liveness probes** проверяют запуск и здоровье контейнеров, requests и limits - потребление ресурсов.

## Взаимодействие
Схема:
Браузер -> localhost:8080 -> front(NGINX) -> /api/ -> Service app:8000 -> FastAPI -> db:5432
                                                                                  -> storage:9000 MinIO
Браузер -> ссылка с ограниченным срокм localhost:9000 -> port-forward -> MinIO
